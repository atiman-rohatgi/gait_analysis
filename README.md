# gait_analysis
(this is a sample level project for showace purposes, utilizing simmilar architecture and framworks)
- Built a Python data processing pipeline on force-sensor gait data from 300+ subjects, extracting biomechanical features for early disease screening, cutting dependence on costly consultations.
- Trained multiple models, selecting Logistic Regression (87% accuracy, 88% recall) over higher-complexity alternatives due to its ability to explain why each patient was flagged, which was critical for clinical trust and adoption.
